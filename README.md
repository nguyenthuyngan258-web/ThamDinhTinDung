# Ứng dụng Thẩm định Tín dụng Khách hàng Cá nhân (Credit Scoring App)

## 1. Giới thiệu dự án
Dự án được thực hiện nhằm mục đích xây dựng công cụ hỗ trợ cán bộ tín dụng thẩm định khách hàng cá nhân dựa trên các chỉ số tài chính cơ bản. Đây là sản phẩm thuộc môn học tại trường **Đại học Tài chính - Marketing (UFM)**.

## 2. Các chức năng chính
* **Thẩm định tự động**: Tính toán nhanh các chỉ số DTI, LTV dựa trên dữ liệu đầu vào.
* **Đánh giá rủi ro**: Phân loại hồ sơ tín dụng theo mức độ rủi ro (Thấp, Trung bình, Cao).
* **Trực quan hóa**: Bảng tóm tắt kết quả chuyên nghiệp, hỗ trợ ra quyết định cho vay.

## 3. Công nghệ sử dụng
* **Ngôn ngữ**: Python
* **Framework**: Streamlit
* **Quản lý phiên bản**: Git & GitHub

## 4. Cách sử dụng
1. Truy cập vào đường link ứng dụng: [DÁN LINK STREAMLIT CỦA BẠN VÀO ĐÂY]
2. Nhập các thông tin tài chính cần thiết vào menu bên trái (Sidebar).
3. Nhấn nút **"Thẩm định ngay"** để xem kết quả phân tích.
